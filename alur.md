Alur presentasi singkat:

1. Admin input nota lewat HP: tanggal, divisi, keterangan, nominal, dan foto bukti.
2. Nota langsung masuk ke super admin untuk diperiksa.
3. Jika benar, super admin approve. Jika salah, reject untuk diperbaiki.
4. Hanya super admin bisa mencetak nota, sehingga nota tidak mudah dipalsukan.
5. Sekali print menghasilkan dua salinan: arsip dan copy.
6. QR pada nota dapat dipindai untuk memastikan pembuat dan status verifikasi.
7. Semua nota otomatis tersimpan, mudah dicari, direkap, dan tidak mudah hilang.

Kalimat penutup:

> “Program ini menggantikan nota manual menjadi proses digital yang cepat dari HP, terkontrol melalui approval, aman saat dicetak, dan rapi untuk pelaporan.”


Alur Miss Tesa:

1. Setelah nota dibuat, admin klik **Salin Pesan WA** lalu kirim ke Miss Tesa.
2. Miss Tesa buka link nota dari WhatsApp untuk melihat detail dan bukti transaksi.
3. Miss Tesa juga bisa masuk ke dashboard pemeriksaan mingguan.
4. Nota otomatis dikelompokkan ke **Minggu 1, 2, 3, dan 4**.
5. Miss Tesa memeriksa nota tiap minggu dan melaporkan nota bermasalah.
6. Minggu ditutup setelah seluruh nota selesai diperiksa.

Kalimat presentasi:

> “Miss Tesa tidak perlu mencari nota kertas satu per satu. Link dikirim melalui WhatsApp untuk pengecekan cepat, sedangkan dashboard mingguan membantu memastikan seluruh nota sudah diperiksa dan tidak ada yang terlewat.”
